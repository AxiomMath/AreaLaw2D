## Statement layer (OpenAI/Statements.lean), 2026-10-12

- Library `OpenAI`, one `[[lean_lib]]` stanza in lakefile.toml; umbrella `OpenAI.lean`
  generated by `lake exe mk_all --lib OpenAI` (umbrella_sync). Namespace `OpenAI`, with
  `open Arealaw`. Nothing under `Arealaw/` changed.
- Starting point: the unpushed `OpenAI/Statements.lean` left by the lost session in
  `the working copy` (built there against main a56d41d). Reviewed against
  the paper and revised; changes listed below.
- Sites: `ℤ × ℤ`, local family `Qudits q := fun _ => Fin q`, so site spaces live in `Type`
  (universe 0). Scalars: any `RCLike 𝕜` in any universe; the paper is over `ℂ`.
- Square lattice: Mathlib `hasse ℤ □ hasse ℤ` (adjacency = Euclidean distance one). A
  `DecidableRel` instance for its adjacency is ours (Mathlib has none for `boxProd`).
- Distance `d_Λ` (§1.1): `domainEDist Λ x y`, the `SimpleGraph.edist` of
  `(hasse ℤ □ hasse ℤ).induce Λ`, in `ℕ∞`, `⊤` across components; `⊤` if a point is outside
  `Λ` (totalization). Never `SimpleGraph.dist`, which is `0` across components
  (`SimpleGraph.dist_eq_zero_of_not_reachable`): a `dist`-diameter would admit disconnected
  supports. Not `SimpleGraph.ediam` either: that is the diameter of a whole graph, while (1.1)
  needs the diameter of a subset in the metric of `Λ` (`domainEDiam`, a `⨆`).
- Ambient distances (§3.2, Def 9.3): `Metric.infEDist` / `Metric.ediam` on the sup metric of
  `ℤ × ℤ` and `ℝ × ℝ`, `⊤` to the empty set as §3.2 requires. Not `Metric.diam` (0 on
  unbounded sets).
- Hamiltonian (1.1): total family `Φ : (X : Finset (ℤ × ℤ)) → Matrix (Reg X) (Reg X) 𝕜`;
  `hamiltonian Λ Φ = ∑_{X ⊆ Λ} extendId (Φ X)` (repo's `extendId`, Arealaw/PTrace.lean);
  `IsAdmissible Λ R J Φ`: every `Φ X` (X ⊆ Λ) Hermitian, L2-operator norm ≤ J, and zero off
  the admissible supports (nonempty, `domainEDiam ≤ R`). Same class of `H` as the paper.
- Gap: `HasGlobalGap H Ω E₀ Δ := Δ • (1 - vecMulVec Ω (star Ω)) ≤ H - E₀ • 1` in Mathlib's
  Loewner order (`open scoped MatrixOrder`, `Matrix.le_iff`). Changed from the lost
  session's explicit `PosSemidef` of the difference (same proposition by `Matrix.le_iff`).
- Ground state: hypotheses `star Ω ⬝ᵥ Ω = 1`, `H *ᵥ Ω = E₀ • Ω`, gap. The paper's
  "unique ground vector up to phase, ground energy E₀" is not a separate hypothesis: for
  `Δ > 0` it follows from these three (to be proved as a lemma later). Dropping it makes the
  statement no weaker. The eigenvector equation is NOT implied by the gap alone (a 2x2
  counterexample with an off-diagonal entry exists), so it is kept.
- Entropy: `(pureState Ω hΩ).regionEntropy hA`, the repo's `SubState.regionEntropy` (nats,
  `Real.log`) of `MState.mk'` of `vecMulVec Ω (star Ω)`; mutual information is the repo's
  `SubState.mutualInfo`. `pureState` takes the normalization proof (an `MState` needs it).
- Edge boundary: `edgeBoundary Λ A := (hasse ℤ □ hasse ℤ).interedges A (Λ \ A)` (Mathlib
  `SimpleGraph.interedges`, ordered pairs out of `A`; same cardinality as the paper's set of
  unordered edges). `innerBoundary` = first coordinates, `cutEndpoints` (`Z_A`) = both.
- Quantifier order of every Hamiltonian statement: `∃ C, ∀ Λ, ∀ Φ (H), ∀ Ω, ∀ E₀, ∀ A`.
- Corollary 1.2: `AreaLawCorollary := AreaLaw 𝕜 q 1 J Δ ∧ ∀ R, VertexAreaLaw 𝕜 q R J Δ`.
  "Every subset of a finite rectangular square lattice" is read as covering both readings
  (A ⊆ rectangle, or the domain Λ ⊆ rectangle): every finite domain is a subset of a
  rectangle, so the first conjunct is Theorem 1.1 at range R = 1 on every domain. Changed
  from the lost session's `AreaLawOnRectangles` (Λ a rectangle only), which was the narrower
  reading. Vertex forms keep the paper's factors 4C and 2C.
- Prop 4.3: `PositiveReplacement 𝕜 q R J Δ p`, `∃ c_* > 0, ∃ C, ∃ c > 0, ∀ Λ Φ Ω E₀`,
  `∀` anchor choices `a_X ∈ X`, `∃ k`. Conditions (4.8), (4.9) and the component support.
  `E_{i,l}` is `condExpect` (normalized partial trace onto `N_l(a_i)`, extended by `extendId`),
  general in the site family. Operator norm: Mathlib L2 operator norm.
- Def 9.3: `IsTemplate Ctpl n s₀ T`: pieces are convex hulls of a nondegenerate rectangle
  (`a, a+u, a+u+v, a+v`, `u ⊥ v` nonzero) or nondegenerate triangle, all sides of slope
  0, ∞, 1, -1; degenerate pieces excluded (paper: "rectangle or triangle"). Lattice sample =
  preimage under `ℤ² → ℝ²`. `IsSeparatedFromCut D₀ s₀ Λ A T := 4 D₀ s₀ < dist_∞(T, Z_A)`.
- Prop 9.6: `CollarBound`: `∀ D₀ > 2R + 10, ∃ Ctpl₀, ∀ Ctpl ≥ Ctpl₀, ∃ C n₀, ∀ Λ Φ Ω E₀ A T n s₀`.
  §3.2 fixes an arbitrary `D₀ > 2R + 10`; Lemma 9.4 needs `C_tpl` sufficiently large. Changed
  from the lost session's `∃ D₀ Ctpl`, which was weaker than the paper's reading. The
  conclusion carries the cut and size bounds the proposition also asserts (|S₀| = O(n²),
  cuts O(n)), since Prop 10.2 consumes them.
- Prop 10.2: `Amplification 𝕜 q R J Δ p`, `∀ C₀ > 0, ∀ M ≥ 1, ∃ C_M n₀, ∀ Λ Φ Ω E₀ A T n`.
  `T` is any finite ambient set (the paper's "ambient set T"). The `L + 2r = o(n^β)` clause
  of (10.16) is not stated: it follows from `r ≤ C_M n^{(1-ε)/α}` because
  `α > 1 - 10⁻⁶` gives `(1-ε)/α < β`. Constants ε = 10⁻⁵, β = 1 - 2·10⁻⁶ written as
  literals; `L = collarWidth n = ⌊n^{1-10⁻⁵}⌋₊`.
- Lemma 11.1: `TwoFamilyCancellation σ loc 𝕜`, general site type and local family (not
  lattice-specific). The two ordered families are the fibres of a label `f : Fin m → Fin 2`,
  each ordered by `Fin m`; any two orders on `I₀`, `I₁` arise this way.
- Proved, not sorried: `instDecidableRelAdjSquareLattice`, `graphNbhd_subset`,
  `domainComponent_subset`. Sorried theorems: `area_law`, `area_law_corollary`,
  `positive_replacement`, `collar_bound`, `amplification`, `two_family_cancellation`.

  `∀ D₀ Ctpl, ∀ n_* ≥ 1, ∃ C, ∀ Λ A` ("Fix the constants D₀ and C_tpl", §11.2), purely
  geometric. Stated as a `def … : Prop` only; NO theorem asserts it, so it adds no `sorry`.
  `ℓ = 10⁻⁵` of (11.1) equals the `ε` of (10.1), so `L_i = collarWidth n_i`.
  `d_Λ` (graph induced on Λ) over pairs in X, not the diameter of the graph induced on X;
  `H Ω = E₀ Ω` is a hypothesis everywhere (with the Loewner inequality alone, any unit Ω
  passes once E₀ is low enough, and Theorem 1.1 would be false); Corollary 1.2 has the edge
  form at R = 1 and the vertex forms `4C|∂_in A|`, `2C|Z_A|` (§1.1, proof on p. 4).
